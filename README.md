# Lumi — پروژه اندروید و ساخت خودکار APK

این پوشه یک اپ اندرویدی کامل است که سایت Lumi (فایل html) را داخل یک WebView بومی
اندروید اجرا می‌کند و با GitHub Actions به‌صورت خودکار برایتان فایل APK می‌سازد؛
دیگر لازم نیست خودتان Android Studio نصب کنید یا دستی چیزی را کامپایل کنید.

## این پروژه چطور کار می‌کند

- کل اپ وب (همان فایل Lumi) در مسیر `app/src/main/assets/index.html` قرار دارد.
- `MainActivity.kt` یک WebView باز می‌کند، آن فایل را لود می‌کند، و پل‌های لازم را
  فراهم می‌کند: انتخاب عکس از گالری (برای عکس پروفایل، رسید پرداخت، استوری)، دسترسی
  به موقعیت مکانی (برای «هم‌شهری‌یاب»)، و باز شدن لینک‌های تلگرام/وب در مرورگر یا
  اپ تلگرام به‌جای خود WebView.
- `localStorage` داخل WebView فعال است (`domStorageEnabled`) چون تمام اطلاعات اپ
  (کاربرها، چت‌ها، پرمیوم، همه‌چیز) همان‌جا ذخیره می‌شود — دقیقاً مثل نسخه وب.
- یک گواهی امضای ثابت (`app/lumi-debug.keystore`) داخل پروژه ساخته و کامیت شده تا
  هر بار که GitHub اپ را می‌سازد، APK با همان امضای قبلی منتشر شود. این خیلی مهم
  است: اگر امضا هر بار عوض شود، کاربرها برای نصب نسخه‌ی جدید مجبور می‌شوند اول
  اپ قبلی را پاک کنند و تمام اطلاعاتشان (حساب، چت‌ها و غیره) از بین می‌رود. با این
  گواهی ثابت، آپدیت‌ها تمیز روی نسخه‌ی قبلی نصب می‌شوند و چیزی پاک نمی‌شود.

## راه‌اندازی (فقط یک‌بار)

1. یک مخزن (repository) جدید در GitHub بسازید، مثلاً به نام `lumi-android`.
2. تمام محتویات همین پوشه را داخل آن مخزن push کنید:
   ```bash
   cd lumi-android
   git init
   git add -A
   git commit -m "Initial Lumi Android project"
   git branch -M main
   git remote add origin https://github.com/USERNAME/lumi-android.git
   git push -u origin main
   ```
3. وارد تب **Actions** مخزن در GitHub شوید و در صورت نیاز آن را فعال کنید
   (گاهی GitHub برای مخازن جدید یک تاییدیه ساده می‌خواهد).
4. همین! به‌محض push شدن، ورک‌فلو (`build-apk.yml`) خودش اجرا می‌شود.

## از کجا فایل APK را بردارم

بعد از اینکه Actions تمام شد (چند دقیقه طول می‌کشد)، دو راه برای گرفتن APK دارید:

- **راه ساده (پیشنهادی):** به تب **Releases** مخزن بروید، یک ریلیز به اسم
  **latest** می‌بینید که فایل `app-debug.apk` به آن پیوست شده — همیشه جدیدترین
  نسخه همین‌جاست و لینکش ثابت می‌ماند، پس می‌توانید همین لینک را برای نصب روی
  گوشی‌ها بفرستید.
- تب **Actions** → روی آخرین اجرای موفق بزنید → پایین صفحه بخش **Artifacts** →
  فایل `lumi-apk` را دانلود کنید (این یک zip است که `app-debug.apk` داخلش است).

برای نصب روی گوشی اندروید: فایل APK را روی گوشی منتقل کنید، آن را باز کنید و
اگر پیام «منابع ناشناس» آمد، اجازه نصب بدهید (چون از گوگل‌پلی نیامده).

## وقتی اپ وب (index.html) را آپدیت کردم چه کار کنم

فقط کافیست فایل جدید را جایگزین `app/src/main/assets/index.html` کنید و دوباره
push کنید؛ GitHub خودش نسخه‌ی جدید APK را می‌سازد و روی همان ریلیز «latest»
آپلود می‌کند. نیازی به تغییر هیچ فایل دیگری نیست.

## نکات فنی

- این یک WebView ساده و بومی است (بدون Cordova/Capacitor) — سبک و سریع.
- حداقل نسخه‌ی اندروید پشتیبانی‌شده: Android 6 (API 23) به بالا.
- دسترسی‌های گرفته‌شده: اینترنت، موقعیت مکانی (اختیاری، فقط وقتی کاربر بخواهد)،
  دسترسی به گالری برای آپلود عکس.
- گواهی امضا (`lumi-debug.keystore`) عمداً در پروژه کامیت شده تا امضا بین
  اجراهای مختلف GitHub Actions ثابت بماند؛ این گواهی را پاک نکنید، وگرنه در
  آپدیت بعدی کاربرها باید اپ را حذف و دوباره نصب کنند و اطلاعاتشان را از دست
  می‌دهند.
- اگر بعداً خواستید اپ را در گوگل‌پلی منتشر کنید، باید یک گواهی امضای release
  جدا (release keystore) با اطلاعات واقعی خودتان بسازید؛ گواهی فعلی فقط برای
  توزیع مستقیم APK (خارج از گوگل‌پلی) مناسب است.
